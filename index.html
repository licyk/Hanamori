WORKFLOW

从下载到第一个 C++ 程序

四个步骤，建立可重复使用的编译环境。

  1. 01

    获取程序

    下载 Windows x64 / ARM64 版本，或按文档从源码构建。

  2. 02

    安装工具链

    使用 install 选择 MSVC 与 SDK，再为组合设置一个别名。

  3. 03

    选择环境

    设置项目文件，在当前终端 use，或者直接 exec。

  4. 04

    编译与运行

    编译 hello.cpp，运行程序，并检查退出状态。

WHY HANAMORI

管理边界清晰，项目彼此独立

工具链选择显式可见，环境变更可以恢复。

  • 不依赖 Visual Studio 安装

    直接解析微软清单与安装包，不依赖 aria2c 或 msiexec。

  • 独立的安装目录

    托管组合独立保存；导入仅建立只读引用，不取得目录删除权。

  • 可恢复的会话

    切换版本不会累积 PATH，退出时恢复激活前的环境。

  • 共享完整下载缓存

    工具链目录保持独立，完整 payload 可以通过内容寻址缓存复用。

  • 先查看，再清理

    卸载和清理提供预览；错误指出保留的内容和恢复方式。
