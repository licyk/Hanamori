下载 Hanamori

获取 Windows x64 / ARM64 程序，然后安装你的第一套 MSVC 与 Windows SDK。

PowerShell 一键安装

在 PowerShell 5.1 或 7 中运行。自动配置用户 PATH、当前 PowerShell 集成与补全，工具链按需安装。

irm https://hanamori.netlify.app/install.ps1 | iex

MSYS2 / Git Bash

配置 Bash 启动入口与补全。安装后重开终端，或执行脚本输出的加载命令。

curl -fsSL https://hanamori.netlify.app/install.sh | bash
