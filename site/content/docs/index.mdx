Hanamori 在独立目录中安装 MSVC 与 Windows SDK，不需要安装 Visual Studio。你可以通过别名或项目文件选择工具链，切换当前终端环境，或为一个构建命令临时准备环境。

<Callout type="info" title="开发版本文档">
本文档对应当前 main 分支。旧版 msvc-installer 发布包没有这里介绍的新命令和状态格式。请先查看[下载页](/download)确认是否已有匹配的新版本；也可以[从源码构建](/docs/build)。
</Callout>

拥有的每套安装使用专属目录，导入的目录只是只读引用。选择工具链不会自动下载；安装工具链也不会自动激活终端。原生编译支持 Windows x64 / ARM64 主机和 x64 / ARM64 目标，其他平台上的测试不代表可以运行 MSVC。详见[支持范围](/docs/support)。
