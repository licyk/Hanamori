在项目根目录创建 `hanamori-toolchain.json`：

```json
{
  "toolset": "14.44.35207",
  "sdk": "10.0.26100.0"
}
```

| 字段 | 含义 |
| --- | --- |
| `toolset` | 必填；实际 MSVC 版本或一至三段数字前缀 |
| `sdk` | 实际四段版本；`null` 表示不使用 SDK；省略表示不约束 |
| `msbuild` | 可选布尔值；`true` 要求 MSBuild，`false` 排除，省略不限制本地选择；安装时默认随 SDK 启用，SDK 为 `null` 时默认关闭 |
| `host`、`target` | 可选 `x64` 或 `arm64`；host 默认为 Windows 原生架构，target 默认跟随 host |
| `vs`、`channel` | 可选来源约束；来源未知的导入记录不能满足 |
| `schema_version` | 可选，目前为 `1` |

未知字段会被忽略。当前目录及祖先中最近的文件生效；最近文件损坏时停止，不跳过它去使用上级文件或默认值。

选择顺序为：显式选择器/目录 → 最近项目文件 → `default`。多个候选匹配会报歧义，要求使用 ID 或别名；不会替你在 SDK 或来源之间选择。选择只查询本地，不自动下载，也不接受浮动 `latest`。

`install` 同样读取项目文件。显式实际版本/SDK 参数覆盖对应字段，下载 ID 则指定要获取的负载，同时保留项目的实际版本约束：

```sh
hanamori install --vs-version 2022 --toolset-id 14.44.17.14 --sdk-id 26100
hanamori use
hanamori exec -- cl.exe /?
```

项目声明不是上游永远提供负载的保证。需要长期复现时保留原安装命令、下载 ID 和相关缓存。项目文件不负责保存本机目录键、别名或当前会话。显式指定托管目录键安装时直接使用该组合，不读取项目文件。
