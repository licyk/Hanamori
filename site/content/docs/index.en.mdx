Hanamori installs MSVC and the Windows SDK in independent directories without a Visual Studio installation. Select a toolchain by alias or project file, activate the current terminal, or prepare an environment for one build command.

Get Hanamori from the [download page](/download), or [build from source](/docs/build).

Each owned installation has an exclusive directory. Imports are read-only references. Selecting tools never downloads them, and installing tools does not activate the current terminal. Native compilation supports Windows x64 / ARM64 hosts and x64 / ARM64 targets; tests on other platforms do not establish MSVC execution support. See [platform support](/docs/support).
