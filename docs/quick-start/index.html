首次编译

从安装工具链到编译、运行一个完整 C++ 程序。

先获取 Hanamori，将 hanamori.exe 所在目录加入 PATH。在一个可写的项目目录中打开 PowerShell。以下命令使用微软默认的 VS 2026 stable 清单；安装需要网络和磁盘空间。

1. 安装工具链

stable 是你创建的本地别名。安装不会自动激活当前终端，default 也只是记录默认选择。最新可用版本取决于所选清单。

2. 保存源文件

这个例子同时使用 C++ 标准库和 Windows SDK，因此不要给安装加 --no-sdk。

3. 编译并运行

exec 不需要 Shell 初始化，编译环境只传递给子进程。PowerShell 中使用 '--'，也能兼容已经加载的 Hanamori 包装函数。预期输出包含 Hello from Hanamori!，进程 ID 每次可能不同。

4. 在当前终端切换

use 按项目文件或默认值选择；若当前目录存在 hanamori-toolchain.json，它优先于默认值。明确指定 hanamori use stable 可覆盖项目选择。deactivate 恢复激活前的环境。希望新终端自动加载钩子，请看启动配置。
